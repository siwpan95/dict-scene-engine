## 1. N4《茶肆·三遇》—— 关系数值情感中篇（15 场景 / ~3.5k 字 / 4 结局）

### 1.1 立意

城南一间老茶肆，三年三遇。补情感第一大类（调研①），用**双轴数值**深化（仿 hushi toleration/independence）：`trust`（信任）/ `closeness`（亲近）。

### 1.2 结构：三幕 + 分流

```
第一遇（春·避雨）→ 夜谈1 → 第二遇（秋·路过）→ 夜谈2 → 第三遇（冬·茶肆要关）→ 夜谈3 → 分流 → 4 结局
```

每幕选项各 ±trust/closeness。结局按双轴组合分流。

### 1.3 结局（4）

| 结局 | 触发 | 情感落点 |
|---|---|---|
| `tea.end-deep` | trust>=2 && closeness>=2 | 深交：留下共守茶肆 |
| `tea.end-trust` | trust>=2 && closeness<2 | 信而不亲：托付茶肆 |
| `tea.end-warm` | closeness>=2 && trust<2 | 亲而不信：温情告别 |
| `tea.end-miss` | 双轴皆低 | 错过：茶肆关了，人散了 |

## 2. N5《机巧阁》—— 程序化解谜机关中篇（14 场景 / ~3k 字 / 3 结局）

### 2.1 立意

山中机巧阁，鲁班传人留下的机关楼。验证"解谜可零改动内容层表达"：`if/do + items` 机关链，fail-forward 不卡死。

### 2.2 机关链

```
阁门（楔子）→ 一层转盘（铜齿轮）→ 楼梯（需铜齿轮）→ 二层齿轮阵（机簧）→ 水漏（玉轴）→ 顶层天工匣（需机簧+玉轴）→ 3 结局
```

### 2.3 结局（3）

| 结局 | 触发 | 落点 |
|---|---|---|
| `gear.end-open` | 集齐机簧+玉轴开匣 | 天工匣：鲁班手记 |
| `gear.end-ruin` | 错解机关（强扭） | 机关反噬 |
| `gear.end-leave` | 中途知难而退 | 下山 |

## 3. S1《最后的水》（短篇 10-12 场景 / ~2k 字 / 2 结局）
