## 1. L2《城破·记与忆》—— 双篇章历史长线（24 场景 / ~6.5k 字 / 5 结局）

### 1.1 立意

对标《哀鸿·城破十日记》双篇章（§4-②），比 N3 戍卒家书更长的长线版：**记篇=围城当下**（点兵/断粮/箭雨/民变/破城），**忆篇=城未破时**（西市/友人/心上人/上元灯会/欠下的债）。半块玉佩跨两篇。

### 1.2 结构

```
start → 记篇 hub（城头，gauntlet 生存线：粮/士气数值）⇄ 忆篇 hub（回忆，branch 情感线）
两篇走完 → merge（信物贯穿）→ 5 结局
```

### 1.3 场景清单（24）

| 组 | 场景 |
|---|---|
| 序 | `siege.start` |
| 记篇 | `siege.record.hub` / `.gate`（点兵）/ `.grain`（断粮分配）/ `.wall`（箭雨修墙）/ `.water`（水井）/ `.letter`（劝降信）/ `.mutiny`（民变）/ `.night`（夜袭守城）/ `.break`（破城三择：死守/出逃/焚城） |
| 忆篇 | `siege.memory.hub` / `.market`（西市）/ `.friend`（友人约定）/ `.love`（心上人）/ `.festival`（上元灯会）/ `.home`（家宅）/ `.debt`（欠下的债）/ `.song`（歌谣） |
| 汇流 | `siege.merge` |
| 结局 | `siege.end-hold`（死守）/ `end-fall`（城破）/ `end-hide`（出逃）/ `end-ash`（焚城）/ `end-echo`（忆篇深线余生） |

### 1.4 状态

- `flags.siege.chap`（'record'/'memory'）、`siegeGrain`（粮 3 起）、`siegeMorale`（士气 3 起）
- `flags.siege.record.*` / `flags.siege.memory.*`（节拍，须被 merge 读）
- `items.halfJade`（半块玉佩，跨篇信物）

## 2. A2《长安·西市》—— 历史都市多 hub 主线（34 场景 / ~9k 字 / 6 结局）

### 2.1 立意

长安西市，天下商贾云集。一封密信在西市转手时失踪，牵出胡商、波斯邸、平康坊歌姬、金吾卫小卒。玩家巡查西市，多 hub 往返，dialogue mode 多角色对话，最后指认。

### 2.2 结构：多 hub + 密信 quest

```
start → 西市十字（hub）⇄ 胡商坊（hub+dialogue）/ 平康坊（hub+dialogue）/ 金光门（金吾卫 dialogue）
     + 勘验（波斯邸/绸缎铺/当铺/波斯寺/暗巷/桥头）→ 三铁证 → 指认 → 6 结局
```

### 2.3 真相与铁证

密信是边关军情，被西市绸缎商钱老板截下，转卖胡商（通敌）。三铁证（`changanEvidence` ≥2 定罪）：密信残页笔迹（当铺兑号）、邸账（波斯邸分账）、证词（歌姬听见夜谈）。

### 2.4 场景清单（34，落地时定稿）

序 1 + 十字 hub 1 + 胡商坊 2 + 平康坊 2 + 金光门 2 + 勘验 7（波斯邸/绸缎铺/当铺/波斯寺/暗巷/桥头/茶肆彩蛋）+ 三铁证 3 + 指认 1 + 结局 6 + 过渡 4 ≈ 32-36

### 2.5 状态

- `changanEvidence`（0）、`changanClues: {}`、`flags.changan: {}`
