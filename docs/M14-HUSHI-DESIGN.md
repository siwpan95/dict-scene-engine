## 1. 定位与命名

| 项 | 值 |
|---|---|
| 内容包 | `content/hushi.js` |
| 命名空间 | `hushi.*` |
| 主线名 | 《藏晖室札记》 |
| 出处 | 留学日记原名即《藏晖室札记》（后改名《胡适留学日记》），`hushi_twrj/1910-1917/markdown/004_自序.md` |
| 接入方式 | `content/demo.js` 的 `start` 场景加一个入口选项（lint 可达性强制） |

**一句话立意**：胡适自序说这十七卷是「一个中国青年学生五七年的私人生活、内心生活、思想演变的**赤裸裸的历史**」。本作不写他的成就，只写他**每次在两个都对的答案之间，选了哪一个**。

**为什么是「主线」而非「短篇」**：现有 17 个内容包里，主线只有《古堡》与《荒漠商队》两条，历史题材只有《江畔·县志》一条中篇（虚构的临江县）。本作是**第一条有真实史料支撑的长线**，且能吃下 `hushi_twrj` 全部 52 年家底。

### 2.3 引用政策（写入 content 文件头）

1. **零噪音分册**（1910-1917 / 1950-1953）的原文可直接入正文。
2. **OCR 卷**只取无歧义短句作「引语」；讹字处（今口→今日、见届→见畀）在正文改写为正确写法，**不臆测补全**。
3. **1938–1944 行程单碎片**（「10:00 颜医生」式）不作场景正文，只作幕间过场的年代感。
4. **回避年份**：OCR 卷 1919/1920（流水账）、1924–1927（分篇崩坏，1926 单篇 6.3 万字）、1941/1948/1949（残片）。

## 3. 机制设计

### 3.1 双轴（取自原文，非杜撰）

`1914.11.3` 那一问，胡适自己给了两个有名字的答案：

| 状态变量 | 原文出处 | 含义 | 增益来源 |
|---|---|---|---|
| `toleration` | 「**为人的容忍**」（Altruistic Toleration） | 为爱我者屈；家庭/人情维度 | 受洗、得冬秀书、容忍迁就、接任大使、诤臣进言 |
| `independence` | 「**不容忍**」之说 | 对一己不可不诚，不可为人屈；社会国家政治维度 | 拒受洗、各行其是、私议改刍议、辞大使、当面逆耳 |

**总纲句直接进 UI**：幕二的分水岭场景标题用「若吾人所持见解与家人父母所持见解扞格不入，则吾人当容忍迁就以求相安乎？抑将各行其是，虽至于决裂破坏而弗恤乎？」

初值 `toleration: 0, independence: 0`，全作累计约 ±8 量级。

### 3.2 贯穿道具：牌

| 变量 | 出现 | 呼应 |
|---|---|---|
| `items.cards` | 1911「相戒不复打牌」（可得/可弃） | 1960「过五关」解闷——**同一道具，五十年，意义翻转** |

其余道具（均为原文实有）：

| 道具 | 出处 | 用途 |
|---|---|---|
| `items.photo` | 全家福照片（卷四） | 冬秀线的具象锚点 |
| `items.willow` | 垂柳图（卷七） | 韦莲司线；原注提到「其一乃雪中之柳也（**此幅今删**）」→ 删掉的那张做隐藏道具 |

| `items.milk_receipt` | 牛奶收据破纸（1950） | 「无用之物」意象；终局文本呼应 |

### 3.3 日记回溯关卡（引擎改动：`mode: 'diary'`）

**原型**：1916 年胡适在韦女士处借回自己三年间寄她的一百多封信，「乃如读小说书，竟不肯放手……他处决不能得此真我之真相也」。

**玩法**：拿到 `items.letters` 后解锁 `hushi.diary`。进入后列出**已走过的篇目**（按幕分组），选一篇**重读**——只读，不执行 `onEnter` 副作用、不显示选项，回车回到回溯点。

**为什么值得做**：这是唯一能让玩家「回看自己选了什么」的机制，与「赤裸裸的历史」立意直接咬合。

**实现规格**（不改核心引擎，走 `scene/mode` 扩展点）：

```js
// plugins/diary.js —— 新插件
export default class Diary extends Service {
  static inject = ['state', 'engine', 'io', 'scenes']
  // 1. 监听 scene/enter，把去过的 hushi.* 场景记入 flags.hushi.read.<id>（自带去重）
  // 2. ctx.on('scene/mode', ...) 对 mode === 'diary' 返回 truthy 接管
  // 3. 接管后：打印已读篇目编号表 → 读输入 → ctx.scenes 取原场景 text 渲染（不走 engine.goto，避免副作用）→ 回车返回
}
```

场景声明：

```js
'hushi.diary': {
  title: '重读 · 旧函',
  text: '……（韦女士旧函百余封）',
  mode: 'diary',
  diary: { onExit: 'hushi.p3.return' },   // 回溯结束回到此场景
},
```

- `cordis.yml` 增加 `- id: diary, name: ./plugins/diary.js` 条目
- lint 增补：非 `normal` 模式豁免「正文 ≥120 字」的 error（现已是 warn，见 `lint-content.mjs:103`）
- 只读渲染复用 `ctx.waterfall('text/render')`，保证插值一致

## 5. 结局矩阵（7）

每个结局挂一句**日记原句**作锚点。

| # | 结局 ID | 标题 | 锚点原句 | 触发条件 |
|---|---|---|---|---|
| 1 | `hushi.end-wherehome` | 吾乡真在何处 | 「凭阑自语，**吾乡真在何处？**」 | 幕三选「留下」 |
| 2 | `hushi.end-sacrifice` | 为国家牺牲了 | 「**二十一年的独立自由的生活，今日起，为国家牺牲了**」 | 幕四接任大使 |
| 3 | `hushi.end-decline` | 辞 | 「我总想辞卸大使事。但拟数电，**均不能满意**。」 | 幕四辞去 |
| 4 | `hushi.end-deserter` | 逃兵 | 「南京作**『逃兵』，作难民，已十七日了！**」 | 1949 上船离开 |
| 5 | `hushi.end-stay` | 留下 | 「不意一月八【日】夜是**最后一次见蒋公**」 | 1949 留在南京 |
| 6 | `hushi.end-remonstrator` | 诤臣一百人 | 「『总统』必须有**诤臣一百人，最好有一千人**。」 | 1953 当面进言 |
| 7 | `hushi.end-cards` | ⭐过五关 | 「**这真是像雷震一样的倒霉**」／「**人到相对无言时是怎样的一种况味**」 | 终局：双轴均衡且持有 `items.cards`（隐藏真结局） |

**设计意图**：结局 2 与 4 构成「牺牲自由」与「被指为逃兵」的对照——同一个人，二十二年间，从「为国家牺牲了」到「作逃兵」，两句都是他自己写的。这是全作最重的一击。

**成就**（`cordis.yml` 增补）：
- `hushi-wherehome` 吾乡真在何处 —— 抵达结局 1
- `hushi-remonstrator` 诤臣 —— 抵达结局 6
- `hushi-cards` 过五关 —— 抵达隐藏结局 7
